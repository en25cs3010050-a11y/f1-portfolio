# F1 Portfolio

Static F1 racing portfolio and dashboard website built from the Arsha Bootstrap template.

## GitHub Pages

The site deploys automatically from the `main` branch with GitHub Actions. After the first successful deployment, it will be available at https://en25cs3010050-a11y.github.io/f1-portfolio/.

The site is static. The template's PHP contact and newsletter handlers are not supported by GitHub Pages, so those forms need a separate service or backend.

## Local preview

Open `index.html` in a browser or serve this folder with a static HTTP server.
